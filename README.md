# High Alch Value Tooltip

A RuneLite plugin that displays live High Alchemy calculations directly on item tooltips when targeting items with the High Level Alchemy spell.

## Features

* **Live GE Calculations:** Fetches current Grand Exchange prices for items and Nature Runes.
* **Profit Margin Analysis:** Calculates net profit margin (`High Alch Value - (Item GE Price + Nature Rune Cost)`).
* **Color-Coded Feedback:** Renders the entire tooltip in **green** for profitable items and **red** for loss-making items.
* **Loss Warning Toggle:** Configurable warning header when hovering over non-profitable alchemy targets.

## Usage

1. Select the **High Level Alchemy** spell in your Magic Spellbook.
2. Hover over any alchemy-eligible item in your inventory or bank.
3. View the calculated tooltip data.

## Configuration

* **Highlight Loss Warning:** Toggles the visual `⚠️ WARNING: NEGATIVE PROFIT! ⚠️` header on non-profitable items.
